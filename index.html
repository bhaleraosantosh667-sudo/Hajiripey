ऑनलाइन सिंकसाठी Firebase

ऑनलाइन डेटा चालू करण्यासाठी Firebase प्रोजेक्ट तयार करा, Authentication मध्ये Email/Password सुरू करा आणि Firestore Database तयार करा. नंतर खालील config फाइलमध्ये तुमची Firebase वेब-कॉन्फिग माहिती भरा.

  1. Firebase Console उघडा आणि प्रोजेक्ट तयार करा.
  2. Project settings → Your apps → Web app जोडा आणि config कॉपी करा.
  3. Authentication → Sign-in method → Email/Password सुरू करा.
  4. Firestore Database तयार करा.
  5. या फोल्डरमधील firebase-config.js फाइलमध्ये config भरा आणि साइट HTTPS वर होस्ट करा.
सुरक्षा: खाली दिलेले Firestore नियम प्रत्येक वापरकर्त्याचा डेटा त्याच्यापुरता मर्यादित ठेवतात. सार्वजनिक read/write नियम कधीही वापरू नका. महत्त्वाचा पगार डेटा आधी तपासूनच वापरा.
